# Clean Start — русификатор

Неофициальный русификатор игры [Clean Start](https://store.steampowered.com/app/3577020/).

- Переведено всё: диалоги, описания предметов, задания, интерфейс, обучение и заставки между уровнями, около 2800 строк.
- В фирменные шрифты игры добавлена кириллица, поэтому русский текст выглядит в стиле оригинала.

## Скачать

**[CleanStart_RU_v1.2.zip](https://github.com/kantemiir/CleanStart-RU/releases/latest)** — раздел Releases, 490 КБ.

Если стоит версия 1.0, запустите установщик новой версии поверх неё: удалять старую не нужно. С версии 1.1 обновляться не обязательно, перевод тот же.

## Установка

1. Закройте игру.
2. Распакуйте архив и запустите `Установить.bat`. Игра найдётся в библиотеках Steam автоматически. Если не нашлась, перетащите папку игры на `Установить.bat`.
3. В главном меню игры: **Options → Game → Language → Russian - русский**.

Русский язык встаёт на место польского, остальные языки не затронуты. Оригинальные файлы сохраняются в `Clean Start\_backup_ru`.

## Удаление

Запустите `Удалить.bat` или проверьте целостность файлов в Steam: Свойства → Установленные файлы.

## Важно знать

- **Версия игры.** Русификатор собран под Steam-сборку 26456990. Установщик проверяет версию по SHA-256 и ничего не меняет, если игра обновилась.
- **Ресурсов игры в архиве нет.** Есть русские строки, два шрифта игры с добавленной кириллицей и служебные данные для установки (`data/files`, `data/patches`). Всё остальное берётся из вашей копии игры.
- **Установщик открытый.** Это скрипт PowerShell в папке [`data`](data), его можно прочитать. Некоторые антивирусы и облачные хранилища реагируют на `.bat`, который запускает PowerShell. Это ложное срабатывание.
- **Качество перевода.** Перевод сделан с помощью ИИ и вычитан выборочно: проверены разметка, имена, род и обращения на «ты» и «вы», интерфейс вычитан полностью. Ошибки присылайте через [Issues](https://github.com/kantemiir/CleanStart-RU/issues) или в обсуждении игры в Steam.
